Dense and late-interaction search in the browser

One SQLite file read with HTTP range requests: FTS5, dense ANN (MiniLM, dense_ann) and late interaction (LateOn-Code-edge, late_plaid). Queries are encoded in the browser with ONNX Runtime Web.
